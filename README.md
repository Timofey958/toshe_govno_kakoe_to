# Doodle Jump ![doodle](assets/player.png)

Упрощеная версия дудл чамп на pygame-ce

## Как запустить

1. Скачать или скопировать ссылку на реопзиторий
    ```bash
    git clone https://github.com/Timofey958/toshe_govno_kakoe_to.git
    ```
1. Запустить main.py
    ```bash
    python main.py
    ```
1. Играй
